# TABANG 2.1.0 — Privacy, Filters and Orientation Update

TABANG is the Transfusion Access, Blood Availability and Network Guidance research prototype for Digos City, Davao del Sur. This release tightens request privacy, improves filter behavior and layout consistency, and adds the final orientation materials.

## Changes

- **Request privacy**
  - Unverified request submissions are no longer shown on the community board or map. Only verified donor-network requests appear.
  - Medical documents, clinical notes and staff review notes are visible only to the requester and chapter staff.
  - A non-owner sees a clear privacy notice instead of another person's uploads.

- **Dropdowns and filters**
  - Searchable pickers no longer focus the search field or open the on-screen keyboard automatically.
  - Small enum lists such as blood type, recipient type, component, urgency and request state no longer show a search box.
  - Result counts remain on every option.

- **Layout and guidance**
  - Inventory tabs stay on one line and scroll horizontally instead of wrapping into an uneven grid.
  - The unit-status legend uses compact status pills plus a help button.
  - Added or aligned guide buttons on Blood Bank, Inventory, Users, Requests, Blood Drives and Moderation.
  - The request filter guide is aligned with the filter toolbar instead of floating between stacked fields.

- **Backend blueprint**
  - The public request projection now covers verified open/matched donor-network requests only.
  - The backend guide, workbook and starter schema reflect the same privacy boundary.
  - Added the complete AI handoff pack under `docs/ai/`.

- **Orientation**
  - Added a video orientation guide, storyboard and full narration script under `docs/presentation/`.

## Quality

- `flutter analyze --no-pub`: clean.
- `flutter test --no-pub`: **213 tests pass**.
- Android: universal plus `arm64-v8a`, `armeabi-v7a` and `x86_64` release APKs.

## Notes

- The app remains a simulated-data prototype. It is not connected to a live hospital, donor registry or Philippine Red Cross system.
- Android release builds use the debug signing key, as documented in `android/app/build.gradle.kts`; replace it before public distribution.
- The Supabase schema is a starter blueprint, not a live backend deployment.
- See `docs/presentation/TABANG_VIDEO_ORIENTATION.md` for the finalized orientation script.
